# Online Bookstore

An online bookstore application developed as a capstone project using Agile Software Development practices.

## Project Goals

- Build a book catalog and search functionality.
- Manage customers and orders.
- Implement purchase transactions with concurrency handling.
- Explore semantic search and book recommendations.
- Design and manage the database using Cloudflare D1.
- Use OpenClaw and Spec Kit to support specification-driven development.

## Technology Stack

- Cloudflare Workers
- Cloudflare D1
- TypeScript
- Node.js and npm
- Git and GitHub
- OpenClaw
- Spec Kit
